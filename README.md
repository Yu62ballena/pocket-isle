# POCKET ISLE（ポケットアイル）

**「3分で溶ける、ちいさな島づくりパズル」**

*Dorfromantik*・*Islanders*・*Triple Town*・*Against the Storm* など、近年の高評価ミニマルシティビルダーの中毒性メカニズムを調査・抽出し、ブラウザでサクッと遊べる1プレイ3〜5分の街づくりゲームとして実装しました。

## 中毒性（「もう1回！」を生む）設計ポイント

1. **ゼロ摩擦のリアルタイム視認性（Low Cognitive Friction）**
   - 6×6 の小さな島マップ。複雑な税金スライダーや細かな管理は排除。
   - マスにカーソルを合わせるだけで**獲得スコア・隣接シナジーの接続ライン・合体予告**がリアルタイムで見える。
2. **隣接シナジー × 3つ合体進化（Merge & Chain）**
   - 民家・公園・市場・工場・港の相性パズルに加え、**同じ建物・同じレベルが3つ隣接すると上位ランク（最大Lv4）に合体進化**。
   - 合体すると元のタイルが空き地に戻るため盤面がスッキリ延命でき、さらに次の3つが繋がれば **CHAIN×2 / ×3 の大連鎖** が発生。
3. **押し引きの手札スタック × ローグライク3択ドラフト**
   - 初期20枚の手札が尽きる前に、**住民のリクエスト達成**や**街ランクUP**で手札を補充し続ける押し引きループ。
   - ランクUPごとに3択の「都市計画ドラフト」が出現し、毎回ちがうビルド（エコ住宅・商業圏・臨海工業・大連鎖特化など）を構築できる。
4. **音階上昇オーディオ & ジュース演出（Game Feel）**
   - Web Audio API によるプロシージャル効果音（外部音声ファイル不要）。シナジー数に応じて**ペンタトニックスケールで音階が駆け上がる**気持ちよさ。
   - 配置時のバウンス、隣接タイルの波紋、大連鎖時の紙吹雪＆画面シェイク、そして街の成長にあわせて **朝 → 昼 → 黄金の夕暮れ → 星降る夜景** へと移り変わる環境演出。
5. **即リトライ & 今日の島（Daily Challenge）**
   - 1クリックで0.2秒リスタート。毎回ランダムな「フリー島」のほか、日付シード固定の「今日の島」、8種類の実績バッジ、街の称号つき絵葉書リザルトを搭載。

## 操作方法

- **クリック / タップ**：手札の建物を島に配置
- **`1` / `2` / `3` キー**：手札のカード切替
- **`Z` キー**：1手戻す（1プレイ2回まで）
- **`R` キー**：すぐやり直す
- **`M` キー**：サウンドのオン／オフ
